# Cat Energy - Nutrition for Your Cat
 
A re-engineering of a static HTML Academy training project into a modern Angular application. The original was a Gulp-based layout exercise; this version rebuilds it from scratch as a component-driven SPA with a structured styling system, lazy-loaded routing, reactive forms, and light/dark theming.
 
**Original (legacy baseline):** [talia-protasova.github.io/cat-energy](https://talia-protasova.github.io/cat-energy/index.html) · [source repo](https://github.com/talia-protasova/cat-energy)
 
---
 
## Tech Stack
 
- **Angular 19** - standalone components, lazy-loaded routes, signals
- **TypeScript 5.7**
- **SCSS** - token-based design system, `data-theme` theming
- **ngx-mask** - phone input formatting
- **Angular Reactive Forms** - validation with accessibility hooks
